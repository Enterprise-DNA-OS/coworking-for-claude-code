# Coworking evidence checks

Checked 6 October 2026. These checks flag missing records for an operator. They do not inspect a site, certify compliance, notify a regulator or replace local advice. Only NZ records receive the NZ checks; AU requirements must be configured for the site's jurisdiction.

| Rule | What the command checks | Source and boundary |
|---|---|---|
| NZ-EMERGENCY | NZ location missing an emergency plan reference or a testing date, or testing date before today. | [WorkSafe emergency plans](https://www.worksafe.govt.nz/managing-health-and-safety/businesses/general-requirements-for-workplaces/emergency-plans/) requires procedures, testing arrangements and worker instruction. The test date is set by the operator. No statutory annual interval is assumed. A reference alone does not verify the plan's contents or implementation. |
| NZ-PRIVACY-REVIEW | Ended NZ member with no retention review date, or a review date before today. | [Privacy principle 9](https://www.privacy.org.nz/privacy-principles/9/) limits retention to lawful purposes. The operator decides lawful purpose and retention duties. Review dates are local policy, not a statutory period; the system never automatically deletes records. |
| OP-INDUCTION | Active member without an induction date. | A local operating check, not proof of a legal breach. [WorkSafe shared workplace guidance](https://www.worksafe.govt.nz/managing-health-and-safety/businesses/what-to-know-about-other-persons-at-work/) describes coordination of shared duties. Set site-specific induction evidence with the operator. |

The emergency evidence review is a draft checklist. The room run sheet is not a real-time evacuation roll; visitors only appear if arrival and departure were recorded. Twelve-hour visitor attention and thirty-day contact attention are operating thresholds, not laws. Active agreements require a supplied reference; the system does not decide legal validity.
