# Why there is no front end

An operator can ask for occupancy, renewal dates or overdue charges and have a coding agent run the matching command against the database. Rules and records remain editable by the business. Read-only HTML reports and draft documents are generated locally.

A member portal provides self-service bookings, mobile access, offline use and a shared calendar people can click. This base does not provide those screens, door controls or automatic billing. It is useful for an operator maintaining the space's records with an agent. Enterprise DNA can scope the screens and integrations a particular business needs through Omni by Enterprise DNA.

The CLI rejects conflicting reservations. It cannot prevent a physical walk-in or a booking recorded in another system. Shared access needs roles, backups and operational monitoring. Read-only reports are snapshots, not a live front end.
